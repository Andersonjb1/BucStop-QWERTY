# Team Cooked Pull Request Policy

## Pre-Submission Requirements

- **Sync with Dev**: Pull request creator must pull from `Dev` branch into their feature branch before creating a new request
  - This helps resolve potential conflicts early

## Conflict Resolution

- **Creator Responsibility**: Pull request creator handles any remaining merge conflict resolutions
- **Pre-check**: Before creating a new pull request, check if existing pull requests are touching the same files and need to be merged first

## Approval Process

- **Required Approvers**: 2 approvers minimum
- **Timeline**: Approvals should be completed quickly to maintain development velocity

## Merging Process

- **Who Can Merge**: Anyone can merge after full approvals are received
- **Conflict Handling**: If merge conflicts remain after approval, the pull request creator handles resolution and merging

## Communication

- **Discord**: Use Discord pings for any needed communication regarding pull requests
