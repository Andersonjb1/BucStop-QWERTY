# Local Deployment Guide

## Prerequisites

Before starting, ensure you have the following installed:

- **.NET Core 6.0** - [Download here](https://dotnet.microsoft.com/en-us/download/dotnet/thank-you/sdk-6.0.428-windows-x64-installer)
- **Git** - [Download here](https://git-scm.com/downloads)
- **Docker Desktop** (optional)
- **Visual Studio** (optional)

## Deployment Steps

### Step 1: Get Source Code

Clone the repository using the following command:

```bash
git clone https://github.com/Christopher-Powers/BucStop-Goofin.git
```

### Step 2: Run Application

You have two options to run the application:

**Option A: Command Line**
1. Navigate to `Bucstop-Goofin/BucStop-WebApp/BucStop/` in your command line interface
2. Run the following command:
   ```bash
   dotnet run
   ```

**Option B: Visual Studio**
1. Open the project in Visual Studio
2. Run the application using Visual Studio's built-in runner
